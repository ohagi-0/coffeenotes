棚の増え方と、珍しい産地

今の「生産国の棚」は 28 か国が最初から全部並ぶ。はじめの人には空き棚ばかりで遠い。ここでは、よく見る 8 か国だけで始めて、そのうち 5 か所をまわったらもう一段（8 か国）増える、そして珍しい産地を飲んだときだけ「珍しい産地」の棚が現れて、ひと演出——という流れを 3 つの状態で見せる。次の段の予告のしかたを 3 案、珍しい産地の演出を 3 案、切り替えて比べられる。店名・豆名は架空。

NOTES

決めること

  • 段の区切り: よく見る 8 / もう一段 8 / 珍しい産地（残り）。数と顔ぶれは「日本の店でよく見る順」で、FAO の生産量順（今の棚）とは別の並びになる。
  • 開く条件: よく見る産地のうち 5 か所（8 の過半数）。「3 か所」だと早すぎてご褒美感が薄く、「8 全部」だとインドネシアやホンジュラスで止まる人が出る。
  • 珍しい産地の判定: 上の 16 に入らない国。語彙に無い国名（「東ティモール」など）も珍しい扱い。ブレンドは対象外。
  • 演出はホームを開いたとき一回: 記録を保存した直後にホームへ戻る流れで出す。二度目以降は残るもの（シール / 淡い光 / メモ）だけ。
  • 戻し方: 設定に「産地の棚を全部見せる」を置くか。コレクションの「すべての豆」は今のまま。
