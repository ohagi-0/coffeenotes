テイスティングカードを、1 分で記録に。

撮って、確かめて、星をつける。店で飲んだ一杯も、自宅で淹れた一杯も、自分で焙煎した豆も、同じ軽さで残せるコーヒーの記録帳。Web スマホ版・Web PC 版・iOS アプリ版の画面設計と、共通のデザインの決めごとをここにまとめた。

DIRECTION

Espresso & Copper

深煎りの豆の色を地にして、銅のケトルの色を一点だけ置く。カードに印刷された英字の豆名と数字をそのまま主役にし、日本語の UI 文言は脇に控える。カフェの薄暗い照明でも、深夜のキッチンでも目が疲れない、ダーク専用の記録帳。

01

カードの言葉をそのまま使う

豆名は英字のまま、コンデンスした書体で大きく組む。標高・価格・湯量比といった数字はラベルの主役として扱い、日本語は説明役に回す。コーヒーバッグのラベルと同じ読み方ができる。

02

銅色は操作できる場所だけ

＋ボタン、保存、星、選択中のタブ。銅色が付いていれば触れる、付いていなければ読むだけ。装飾には一切使わない。要確認は琥珀、削除と失敗は錆色で、銅と混ざらないようにする。

03

片手で、親指で

主操作は画面下 1/3 に集める。タップ領域は 44px 以上。星は左半分・右半分のタップで 0.5 刻み。レシピや焙煎の詳細は折りたたみ、星とメモだけなら 3 タップで保存できる。

COLOR & TYPE

色と書体

アプリはダーク専用。ライトテーマは提供しない。色はすべてトークンで定義し、コンポーネントは色を直接持たない。書体は Bodoni Moda + Manrope + 端末の日本語フォントで確定（ADR 0006）。

COMPONENTS

部品

この記録帳にしか無い部品を先に決める。星の半分タップ、味覚チャート、読み取り結果の要確認、店 / 自宅の切り替え。

星評価 — 0.5 刻み、左右半分タップ

4.5

星の左半分を押すと .5、右半分で .0。数値を隣に出して確定値を必ず見せる。スライダーでも入力可（アクセシビリティ要件）。

味覚チャート — 5 軸、5 段階

カードのドット表現をそのまま UI に。ドットをタップして入力、未入力の軸は空のまま保存できる。

このデザインが決まったら

基本設計書は docs/DESIGN.md、決定は ADR 0006（色・書体）と ADR 0007（PC 版・iOS 版）。以後の変更はモックと DESIGN.md を同時に更新する。

docs/DESIGN.md

トークン、書体、部品仕様、画面ごとの要素・状態・遷移・対応する要件 ID。実装はこの文書を正とし、このモックは見た目の参照。

Tailwind / shadcn テーマ

ここで決めた色をそのまま CSS 変数として globals.css に落とす。ダーク専用なので color-scheme は dark 固定、ライト用の変数は持たない。

フォントの導入

Bodoni Moda と Manrope を next/font で読み込み、PWA のオフライン閲覧でも崩れないようにする。日本語は端末フォントなので読み込みは欧文 2 書体だけ。

ADR 0006

「ダーク専用・銅アクセント・Bodoni Moda + Manrope」の決定を残した（docs/decisions/0006）。
