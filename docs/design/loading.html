読み込みの動き — 3 案

ログイン直後や画面を開くときの「読み込み中…」を、回るだけの印から、コーヒーの所作の小さな動きに替えた（2026-10-20 に採用。アプリでは 3 つのうち 1 つをランダムに出す。`components/loading-scene.tsx`）。線は銅と生成り、面は使わない。CSS だけで動き、「動きを減らす」設定の端末では止めて絵だけにする。

COMPARE

3 つの所作

A · ハンドドリップ
お湯を注いでいます…

形は定番の道具に寄せた（ロゴは付けない）: 円すい型ドリッパーはらせんのリブと底のリング、ガラスサーバーは丸い胴と首の黒い帯、ケトルは逆台形の胴に長く細い注ぎ口と後ろに張り出した握り（電気ケトルの定番の形）。ケトルが右上から寄ってきて、「の」の字（時計回りの小さな円、2.6 秒で 1 周）を描きながら注ぐ。湯の筋もケトルと一緒に回るので、落ちる場所が円を描く。滴は重力の緩急で落ち、サーバーの水面が上がる。注ぎ終えるとケトルが引き、一呼吸おいて最初から。8 秒で一巡。文言は「お湯を注いでいます…」。

B · 焙煎（手網）
豆を煎っています…

自家焙煎の定番、手網。金網のかご（網目の柄）と長い柄を、五徳の上で左右に振る。中の豆が 7 粒、少しずつずれて跳ね、色は生豆の緑 → 黄 → シナモン → 茶 → 深煎りへ 9 秒で。深煎りに入ると薄い煙、ときどきチャフが舞う。文言は「豆を煎っています…」。

C · 手挽きミル
豆を挽いています…

縦長の筒に木目、上に金属の蓋、下にガラスの受け、という手挽きミルの定番の形。蓋の中心から出たクランクが上から見た楕円の軌道で回り、先の木の握りが手前で大きく奥で小さく見える。筒がわずかに揺れ、受けに粉が溜まっていく。9 秒で一杯。文言は「豆を挽いています…」。

NOTES

使い方

  • 出る場所: ログイン判定の間の全画面、各ページの初期読み込み（`FullScreenLoading`）。ボタンの中の小さな回転は今のまま。
  • 文言は所作に合わせて変える。読み上げは「読み込み中」のまま（`role="status"`）。
  • 「動きを減らす」設定の端末では止め、絵だけ出す。
  • 決まったら `components/full-screen-loading.tsx` を差し替え、DESIGN.md §4 の部品に追記する。
