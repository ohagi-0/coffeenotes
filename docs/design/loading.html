読み込みの動き — 3 案

ログイン直後や画面を開くときの「読み込み中…」を、回るだけの印から、コーヒーの所作の小さな動きに替える。線は銅、面は使わない。どれも 140px、CSS だけで動き、「動きを減らす」設定の端末では止めて印だけにする。

COMPARE

3 つの所作

A · ハンドドリップ
お湯を注いでいます…

ケトルは画面の外。注ぎ口だけが右上から入ってきて、細い湯の筋が揺れながら円すいへ。滴は重力の緩急で落ち、サーバーの中で水面（メニスカス）が上がる。注ぎ終えるとケトルが戻り、一呼吸おいて最初から。8 秒で一巡。文言は「お湯を注いでいます…」。

B · 焙煎
豆を煎っています…

ドラムの穴あき板がゆっくり回り、中の豆がかき上げられては落ちる（6 粒を少しずつずらした転がり）。色は生豆の緑 → 黄 → シナモン → 茶 → 深煎りへ 9 秒で。深煎りに入ると薄い煙、ときどきチャフが舞う。火は下で揺れる。文言は「豆を煎っています…」。

C · 手挽きミル
豆を挽いています…

鋳物の椀と木の箱の手挽きミル。ハンドルは上から見た楕円の軌道で回り（奥で細く、手前で太く見える）、胴がわずかに揺れる。数秒おきに豆が椀へ落ち、引き出しに粉が溜まっていく。9 秒で一杯。文言は「豆を挽いています…」。

NOTES

使い方

  • 出る場所: ログイン判定の間の全画面、各ページの初期読み込み（`FullScreenLoading`）。ボタンの中の小さな回転は今のまま。
  • 文言は所作に合わせて変える。読み上げは「読み込み中」のまま（`role="status"`）。
  • 「動きを減らす」設定の端末では止め、絵だけ出す。
  • 決まったら `components/full-screen-loading.tsx` を差し替え、DESIGN.md §4 の部品に追記する。
