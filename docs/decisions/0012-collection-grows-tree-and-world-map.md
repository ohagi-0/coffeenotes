# 0012: 記録が増えると育つもの — コーヒーの木と飲んだ産地の地図

- 日付: 2026-10-21
- ステータス: 決定
- 関連要件: F-LIST-4（コレクション S10）

## 背景

コレクション（棚）は、棚が埋まり切ると変化が止まる。「件数を記録するほど豊かになる」部分が棚の埋まり方しかなく、記録を続ける理由が弱い（2026-10-20 の Kota との相談。試作は `docs/design/room.html` と `world.html`）。ゲームのレベルやポイント、連続記録日数は、記録帳の性格と合わないので使わない。

## 選択肢

1. **産地ごとに木が 1 本**。その国の杯数で苗 → 若木 → 葉が茂る → 実、と本物のコーヒーの木の順に育つ。直近 30 日に飲んだ国には白い花。木の本数で 鉢 → 畑 → 丘の農園と景色が広がる。
2. 全部の記録で 1 本の木が大きくなる。分かりやすいが、棚との対応が無く、300 杯あたりで育ち切る。
3. 棚の周り（壁、机の上の道具）が杯数の節目で変わる。

地図は、生産国の棚を世界地図で見せる案 1 つ（塗りの濃さ 3 段、コーヒーベルトの点線、ベルトに寄せた表示を既定）。

## 決定

- 木は **1（産地ごと）**。空き棚 = まだ植わっていない木、と棚・地図と同じ単位で揃う。段階は 1 / 3 / 6 / 10 杯、花は直近 30 日、実は杯数ぶん（上限 12）。鉢は 1〜2 本、畑は 3〜7 本、丘の農園は 8 本から。ホームの杯数の下に 1 枚の絵として置く。
- 地図はホームの見せ方チップに「産地の地図」を足す。塗られていない国を押すと「飲める店を近くで探す」（Google マップの検索 URL）と「豆を買う」（Google 検索）の出口。アフィリエイトは入れない（入れるなら REQUIREMENTS §8.3 で決めてから）。
- 絵は SVG を手続きで描き、画像は持たない。緑は木にだけ使う（ダーク + 銅の配色は変えない）。

## 理由

- 産地単位にすると、棚（28 か国）・地図・木が 1 つの考え方で揃い、説明が要らない。
- 木の成長の段階が本物のコーヒーの木と同じ（苗、開花、赤い実）なので、コーヒー好きには納得感があり、ライト層には「育っている」だけで通じる。
- 地図の国の形は Natural Earth 110m（パブリックドメイン）。`src/components/beans/world-map-data.ts` は生成物（約 120KB、「産地の地図」を開いたときだけ読み込む）。作り直すときは world-atlas の `countries-110m.json` を topojson-client で GeoJSON にし、d3-geo の `geoNaturalEarth1().fitSize([960, 480], sphere)` で投影して、南極（id 010）を除き、ISO 数値コードの無い地域は `iso: -1` にする。
