# 0006: ビジュアルデザインはダーク専用・銅アクセント・Bodoni Moda + Manrope

- 日付: 2026-09-21
- ステータス: 決定
- 関連要件: §5 画面構成、§6 非機能要件（アクセシビリティ）、F-LOG-2、F-OCR-5

## 背景

Phase 1 の画面実装に入る前に、色・書体・部品の基本方針を決める必要があった。要件定義書 §12 の競合調査では、記録系アプリの多くが白地に汎用的なサンセリフで、見た目の差が無い。本アプリは「店タグ × 地図」「店でも自宅でも同じ軽さ」を差別化の核にしており、見た目でも「コーヒーの記録帳」と一目で分かる固有の識別性を持たせたい。モックアップは `docs/design/index.html`（公開: https://ohagi-0.github.io/coffeenotes/design/ ）。

## 選択肢

### テーマ

1. ライト既定、ダークは OS 追従
2. ダークとライトの両方を同等に用意
3. ダーク専用

### 書体（豆名 / 数字 / 日本語 UI）

- A. Bodoni Moda / Manrope / 端末の日本語フォント（Hiragino Sans、Noto Sans JP）
- B. Syne / Geist / Noto Sans JP（Web フォント）
- C. Cormorant Garamond イタリック / Manrope / しっぽり明朝 B1
- 初案: Archivo（コンデンス） / Archivo / Zen Kaku Gothic New

### アクセント

- 銅（#D48C4E）を操作要素だけに使う
- テラコッタ + クリーム地（コーヒー系アプリの定番）

## 決定

- テーマは **3. ダーク専用**。ライトテーマは実装しない。`color-scheme: dark` を固定し、ライト用の変数を持たない。
- 書体は **A**。豆名とワードマークに Bodoni Moda、数字・日付・データに Manrope、日本語 UI は端末フォントのスタック。Web フォントとして読み込むのは欧文 2 書体のみ。
- 地は Espresso #17120F、文字は Crema #F1E8DA、アクセントは Copper #D48C4E。銅は「触れる場所」（＋、保存、星、選択中タブ）にだけ使い、装飾には使わない。要確認は Amber #E3A94D、削除・失敗は Rust #D96A57 で銅と分離する。
- トークン一覧と部品仕様は `docs/DESIGN.md` を正とする。

## 理由

- **ダーク専用**: 主な利用場面はカフェの薄暗い照明と深夜のキッチンで、ダークの方が目に優しい。2 テーマを同等に保守するコストは個人開発では重く、初案のライト表示はレビューで「不要」と判断された。テーマ切り替えを持たないことで、部品の状態数と QA 項目が半分になる。
- **書体 A**: 高コントラストのボドニは豆名を「ラベル」として際立たせ、他の記録アプリとの識別性が最も高い。日本語を端末フォントに任せることで日本語 Web フォント（数 MB）の読み込みが不要になり、PWA の初回表示とオフライン閲覧が軽くなる。B は勢いがあるが日本語 Web フォントが必須で重く、C は落ち着くがモダンさに欠けると判断した。3 組をモック上で切り替えて比較したうえでユーザーが A を選んだ。
- **銅アクセント**: コーヒー器具（ケトル、グラインダー）の色で主題と結びつく。テラコッタ + クリーム地は AI 生成デザインとコーヒー系アプリの両方で既視感が強く避けた。
