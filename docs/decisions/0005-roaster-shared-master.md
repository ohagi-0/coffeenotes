# 0005: ロースター名は全ユーザー共通マスタ

- 日付: 2026-09-21
- ステータス: 決定
- 関連要件: F-BEAN-2、REQUIREMENTS.md §4.3

## 背景

ロースター名（例: KIELO COFFEE）は複数ユーザーが同じ店を登録する可能性が高く、将来の名寄せや統計のために共通化したい。一方、ユーザーごとのデータ分離（F-AUTH-2）との整合が必要。

## 選択肢

1. ユーザーごとに `roasters` を持つ（完全分離）
2. 全ユーザー共通のマスタにする（読み取り全員可、書き込み認証ユーザー可）
3. 管理者のみ編集可能なマスタにする

## 決定

2 を採用。`roasters` は RLS で「読み取り全員可 / INSERT 認証ユーザー可 / UPDATE・DELETE は `created_by` 本人のみ」とする。登録時は `name` の大文字小文字・前後空白を正規化した列（`name_normalized`）で一意制約を張り、重複を避ける。表記ゆれの統合（名寄せ）は将来の課題とする。

## 理由

完全分離だと同じロースターが多数重複し、将来の名寄せコストが増える。管理者のみ編集だと新しいロースターの登録がユーザーの手を止める。共通マスタなら登録の軽さと将来の統合を両立でき、RLS で他人の登録を書き換えられないよう制限できる。
