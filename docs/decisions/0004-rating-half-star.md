# 0004: 星評価は 0.5 刻み

- 日付: 2026-09-21
- ステータス: 決定
- 関連要件: F-LOG-2

## 背景

星評価は「自分の好み」を表す主要指標で、統計（F-STAT-2）の閾値にも使う。刻み幅は DB 型と UI の両方に影響するため先に決める必要があった。

## 選択肢

1. 1 刻み（1〜5 の整数）
2. 0.5 刻み（1.0〜5.0）
3. 0.1 刻みや 10 点満点

## 決定

2 を採用。DB は `numeric(2,1)` とし、CHECK 制約で `1.0〜5.0` かつ `rating * 2` が整数であることを保証する。UI は星の左半分／右半分タップで半星を入力し、スライダーでも入力可能にする。

## 理由

1 刻みでは「4 と 5 の間」を表せず、好みの比較に粗すぎる。0.1 刻みは入力負荷が高くスマホの片手操作に向かない。0.5 刻みは他の記録アプリでも一般的で、星 UI に自然に対応する。
