# 0009 豆のコレクションの棚の並び順と品種リスト

日付: 2026-09-24

## 背景

ホーム（S10 豆のコレクション）は飲んだ豆を「生産国の棚」「品種の棚」に並べ、まだ飲んでいない国・品種は空き棚として見せる。2026-09-24 の実装時は、生産国を地域順（アフリカ → 中東 → 中米 → 南米 → アジア → 太平洋）、品種を植物学の系統順（エチオピア由来 → ケニア系 → ティピカ系 → ブルボン系 → 大粒種 → 新しい品種 → ハイブリッド）に手で並べていた。

同日のレビューで次の問題が出た。

- 棚の順に根拠が無く、どこに何があるか説明できない。
- 品種の 28 種は「植物学上の品種」で選んでいたため、店で「ブルーマウンテン」と書かれた豆を記録した人が、アプリの中でティピカの棚に入れられるか、末尾の「その他」に追いやられる。ライト層（CLAUDE.md §1「想定ユーザー」）には意味が分からない。
- 「アラビカ / ロブスタ」を品種欄に書く人がいるが、ほぼ全部アラビカなので棚にしても意味が無い。

## 選択肢

### 生産国の並び順

| 案 | 内容 | 評価 |
|---|---|---|
| A. 地域順（現状） | 大陸ごとに固定 | 根拠が説明しにくい。よく見る国が散らばる |
| B. 生産量順 | FAO の生豆生産量の順 | 根拠が明確で更新もできる。ベトナム・ウガンダなど店で見ない国が上位に来るが、ユーザーに順の理由が伝わらなくても困らない |
| C. 日本の店で見る頻度順 | 手で順位付け | ユーザー体験には近いが主観で、更新の根拠が無い |
| D. 飲んだ棚を上、空き棚を下 | 記録次第で並びが変わる | 「棚が埋まっていく」感じが薄れる（Kota の指摘） |

### 品種のリスト

| 案 | 内容 | 評価 |
|---|---|---|
| E. 植物学の品種のまま別名を足す | ブルーマウンテンをティピカの別名に | 正しいが「なんのこっちゃ」になる |
| F. 店のカードに書かれる言葉を棚にする | ブルーマウンテンは独立した棚。系統名は見出しに出さない | ライト層の体験に合う。順は店で見る頻度で決める（主観） |

## 決定

- 生産国は **B. 生産量順**。出典は FAO（FAOSTAT）の 2023 年生豆生産量（Wikipedia「List of countries by coffee production」経由で 2026-09-24 に確認）。上位から: ブラジル、ベトナム、インドネシア、コロンビア、エチオピア、ホンジュラス、ウガンダ、ペルー、インド、グアテマラ、メキシコ、ラオス、ニカラグア、中国、コスタリカ、タンザニア、ケニア、パプアニューギニア、エルサルバドル、イエメン、ルワンダ、ボリビア、タイ、パナマ。FAO の表（年 1 万トン以上の 36 か国）に無いブルンジ・エクアドル・ジャマイカ・ハワイは、生産量の目安の順で末尾に置く。ジャマイカは「ブルーマウンテン」を別名に持たせるために追加した（28 か国）。
- FAO の表にあっても日本の店でまず見ない国（中央アフリカ、ギニア、コートジボワール、コンゴ民主共和国、ベネズエラ、マダガスカル、フィリピン、カンボジア、ドミニカ、トーゴ、アンゴラ、マラウイ）は棚にしない。空き棚が増えるほど「制覇」が遠のくため。入力されればその名前の棚になる。
- 品種は **F**。リストは「日本のスペシャルティコーヒー店のカードで見かける頻度」で Claude Code が順位付けした 25 種（主観。`src/lib/vocab/varieties.ts` が正）。ブルーマウンテンは独立した棚、系統名（ケニア系、ハイブリッド）は見出しにも補足にも出さない。アラビカ / ロブスタ（種の名前）は棚にせず、品種欄がそれだけなら「品種なし」と同じ扱い。
- 並び順の「よく見る」判断を後で入れ替えるときは、`COUNTRY_SHELVES` / `VARIETY_SHELVES` の配列の順を変えるだけでよい。

## 理由

- ユーザーが順の理由を知らなくても、上の方によく見る国が来ていれば体験として十分（Kota、2026-09-24）。生産量順は根拠を残せて、翌年の統計で機械的に更新できる。
- 棚の見出しは「その人がお店で見た言葉」にする、という CLAUDE.md §5.3 の方針をそのまま適用した。
